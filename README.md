# Subtitle Generator

Next.js (App Router, TypeScript) app that will turn English audio or video into speaker-labelled subtitles.

Requires **Node.js 20** (developed on v20.20.2).

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). You should see a placeholder home page.

AssemblyAI (SDK, API routes, and `.env.local`) is added in later tasks. Do not put API keys in this repo.
